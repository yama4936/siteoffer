# 納品用サイトの構成（delivery_site.v1）

顧客が確認した情報・素材・契約範囲に基づき、公開する1ページサイトのテンプレートに渡す構成JSONを作る。

- 使ってよいのは確認済みの事実だけ。デモの文章を流用する場合も、確認済みの事実と食い違う部分は直す。
- companyInfo・contact は確認済みの事実の値をそのまま使う。なければ null にする。
- achievements と companyInfo.licenses は、確認済みの事実に対応するものだけを書き、factRef にその key を書く。
- 補足の区画にある契約範囲を超える要素（予約・決済・多ページ等）を足さない。
- colors は顧客が確認した色の指定があればそれに従う（#RRGGBB形式）。
