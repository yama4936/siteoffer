# 電話台本（call_script.v1）

営業ユーザーが企業の代表窓口に電話するときの台本を作る。

- opening で名乗り、用件を短く伝える。提案用のデモは企業の依頼によらない非公式のものであることを伝える。
- sections は「用件の説明」「現状の課題（観測した事実だけ）」「提案の内容」「次の約束（資料送付・提案リンクの案内）」の順を基本にする。
- onDecline には、断られたときに丁寧に引き下がり、今後の連絡を控える旨を伝える文言を書く。しつこく食い下がらない。
- doNotSay には、言ってはいけないこと（未確認の実績・料金の断定・効果の約束・企業や既存の制作会社への批判）を書く。
- 料金・契約条件は、補足の区画に確定した値がある場合だけ伝える。なければ「担当から改めてご案内します」とする。
