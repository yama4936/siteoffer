# 提案用サイトデモの構成（demo_site.v1）

企業向け1ページサイトのテンプレートに渡す構成JSONを作る。デモは営業時に見せる非公式の提案で、公開前に顧客の確認を経る。

- companyName・catchphrase・services は、確認済みの事実と既存サイトの観測から作る。
  サービス名は既存サイトの表記に合わせ、存在しないサービスを足さない。
- companyInfo・contact は確認済みの事実の値をそのまま使う。なければ null にする（仮の住所・電話番号を入れない）。
- achievements と companyInfo.licenses は、確認済みの事実に対応するものだけを書き、factRef にその key を書く。なければ空配列。
- 顧客の声・受賞・料金は、確認済みの事実にない限り書かない。
- colors は既存サイトの印象を参考に、文字と背景のコントラストが十分な組み合わせにする（#RRGGBB形式）。
