# 想定問答（faq.v1）

営業の電話・面談で企業から出そうな質問と、その回答を作る。

- 質問の分類（category）：料金（price）、範囲（scope）、進め方（process）、ドメイン（domain）、信頼（trust）、その他（other）。
- 回答は補足の区画にある商品範囲・条件と、確認済みの事実だけに基づく。決まっていない条件は「担当から改めてご案内します」とする。
- ドメインについては、継続・移管・新規取得の希望を聞き取ることまでを答える。移管の手続きや認証情報の扱いを営業が引き受ける回答にしない。
- 回答が依拠する確認済みの事実があれば、その key を factRefs に書く。
